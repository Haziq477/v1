# CityGovApp Landing Page

- **Entry file**: `index.html`
- **Styles**: `styles.css`
- **Assets**: PNG files in the project root

## Run locally in VSCode

- Option 1 (recommended): Install the VSCode extension “Live Server”, then right‑click `index.html` → "Open with Live Server".
- Option 2 (Python):
  ```bash
  cd /workspace
  python3 -m http.server 5500
  ```
  Then open `http://localhost:5500` in your browser.

CDN dependencies (Bootstrap and AOS) require internet access.
